# Project summary

This repository is a leakage-aware AI-for-science prototype for black-hole-hair
identifiability. It combines analytic leading-eikonal simulation, PCA curve
compression, grouped inverse regression, model-family classification, numerical
Jacobian sensitivity, replaceable geodesic-observable proxies, and an optional
GWOSC/LVK posterior-scale demonstration.

The central conclusion is methodological: strong average prediction does not imply
uniform physical identifiability. Dense Kiselev interpolation is accurate, yet the
inverse map becomes locally rank-deficient at the zero-hair limit. Independent
observables probing different radial structure are the next physics target.

Status: poster-ready research prototype; not yet a journal-ready observational
analysis.
