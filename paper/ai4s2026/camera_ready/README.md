# NeurIPS 2026 AI for Science camera-ready manuscript

This directory contains the final seven-page camera-ready source supplied as
`camera_ready.tex`, the NeurIPS 2026 style file, and the authentic figure assets
used by the main manuscript.

Compile from this directory with:

```powershell
tectonic camera_ready.tex
```

The resulting PDF is `camera_ready.pdf`. The four files under `figures/` are
repository copies of the corresponding scientific figures; they are not
placeholders or manually cropped images.

The long-form scientific manuscript remains separately maintained under
`paper/current_study/manuscript/`.
