# Reproduction entry points

- `python -m bhhairml.workflows.reproduce_current_study`: archived-data claim audit.
- `python -m bhhairml.validation.physical_shooting_ml_validation`: registered HGB/RF/MLP analysis.
- `python -m bhhairml.validation.journal_phase_convergence`: uniform 161-phase audit.
- `python -m bhhairml.validation.targeted_321_audit`: targeted 321-phase audit.
- `python -m bhhairml.validation.global_ambiguity_audit`: finite-domain ambiguity analysis.
- `python -m experiments.traditional_inverse_baselines.evaluate_nearest_baseline`: nearest-model inverse.
- `python -m experiments.traditional_inverse_baselines.evaluate_jacobian_baseline`: local-Jacobian inverse.

The first command is the reviewer-facing default and never launches shooting.
